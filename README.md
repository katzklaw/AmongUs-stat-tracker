# Among-Us-stat-tracker
Drag and drop log files generated by [Twix's game logger](https://github.com/whichtwix/GameLogger) or my [updated version](https://github.com/katzklaw/TwixLogger) and this utility will automagically spit out searchable stats so you can check your win/loss rates.
